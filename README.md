# Neo4j Express Social API

A simple **Node.js + Express + Neo4j** project that demonstrates how to build a social network graph API.  
It shows how to manage users, friendships, and movie ratings using **Neo4j Graph Database**.

---

## 🚀 Features
- Create users with properties (name, age).
- Create friendships between users.
- Rate movies with stars.
- Query friends of a user.
- Query movies rated by a user.
- Simple recommendation queries.

---

## 🛠 Tech Stack
- **Node.js** (Express.js)
- **Neo4j** (Graph Database)
- **neo4j-driver** (official JS driver)
